SMART EXPENSE TRACKER - FINAL VERSION

TECHNOLOGIES
Python + Tkinter + SQLite + CSV
No Flask, no Django, no external packages.

FEATURES
1. Calendar date picker
2. Description example/placeholder
3. Add expense
4. Edit expense
5. Delete expense
6. Dashboard: total, today, this month
7. Monthly budget and warning
8. Search
9. Month filter (January to December)
10. CSV export
11. Category-wise summary
12. Category expense bar chart
13. Dark Mode / Light Mode
14. SQLite permanent storage

RUN
1. Install Python 3.
2. Extract this ZIP.
3. Open the folder in VS Code.
4. Open Terminal.
5. Run:
   python expense_tracker.py

The expenses.db file will be created automatically.

RESUME DESCRIPTION
Smart Expense Tracker | Python, Tkinter, SQLite
Developed a desktop expense management application with calendar-based
date selection, CRUD operations, searchable and filterable records,
monthly budget monitoring, dashboard summaries, category-wise analytics,
expense charts, CSV export, dark mode, and SQLite database persistence.
