# Smart Expense Tracker

## Project Overview
Smart Expense Tracker is a Python-based desktop application that helps users record and manage their daily expenses. It provides a simple interface to organize expenses and monitor spending.

## Technologies Used
- Python
- Tkinter
- SQLite

## Features
- Add and manage daily expenses
- Store expense records in a database
- Organize and review spending
- User-friendly desktop interface

## Project Structure
- `expense_tracker.py` – Main Python application
- `expenses.db` – SQLite database
- `requirements.txt` – Required dependencies

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Install the required dependencies, if any.
5. Run the application:

```bash
python expense_tracker.py
```
